# Quebra de Tarefas

## Organização

Como vou fazer o projeto sozinho, todas as partes serão feitas por mim. Para deixar o trabalho mais organizado, separei as atividades em etapas.

## Responsável

### Desenvolvedor

Vou ficar responsável por:

- Escolher e definir o tema do sistema;
- Criar a pasta Planejamento no repositório;
- Fazer a descrição do projeto;
- Criar os protótipos das telas;
- Criar os fluxos do sistema;
- Planejar a arquitetura do projeto;
- Definir as rotas públicas e privadas;
- Criar a estrutura do projeto em Node.js;
- Configurar o Express;
- Criar controllers, services e repositories;
- Criar os middlewares;
- Fazer as telas em HTML;
- Criar o CSS e o JavaScript;
- Testar o funcionamento do sistema;
- Corrigir erros;
- Organizar tudo no Git.

## Etapas

### Etapa 1 — Planejamento

Nesta etapa vou definir a ideia principal do sistema, as funcionalidades, as entidades e organizar os arquivos iniciais do projeto.

### Etapa 2 — Protótipos e Fluxos

Nesta etapa vou criar as telas do sistema e os fluxos de funcionamento, mostrando como o usuário vai navegar e usar o sistema.

### Etapa 3 — Parte Técnica

Nesta etapa vou planejar a estrutura de pastas, as camadas do projeto, os controllers, services, repositories, middlewares e rotas.

### Etapa 4 — Backend

Nesta etapa vou criar a base do projeto com Node.js e Express, configurar as rotas, sessões, middlewares e a lógica principal do sistema.

### Etapa 5 — Frontend

Nesta etapa vou criar as páginas HTML, o CSS, o JavaScript e integrar os formulários com o backend.

### Etapa 6 — Testes

Nesta etapa vou testar cadastro, login, criação de tickets, listagem, respostas, rotas privadas e páginas de erro.

Mesmo fazendo sozinho, separei as tarefas por etapas para conseguir acompanhar melhor o andamento do projeto e garantir que todas as partes sejam entregues.
